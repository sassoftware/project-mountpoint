# Project Mountpoint Appendix

To help aid with infrastructure readiness, we have provided examples of scripts, utilities, and other resources to help provision physical storage or otherwise aid in the tasks described.

**This information is beyond the intended scope of Project Mountpoint**. It is provided for educational purposes. The user is expected to have the skills and privileges to implement these on site.

As always, refer to the **SAS Infrastructure-as-Code** projects for a good place to get started with infrastructure provisioning:

- [viya4-iac-aws](https://github.com/sassoftware/viya4-iac-aws): Amazon Web Services
- [viya4-iac-azure](https://github.com/sassoftware/viya4-iac-azure): Microsoft Azure
- [viya4-iac-gcp](https://github.com/sassoftware/viya4-iac-gcp): Google Cloud Platform
- [viya4-iac-k8s](https://github.com/sassoftware/viya4-iac-k8s): Upstream, open-source Kubernetes
