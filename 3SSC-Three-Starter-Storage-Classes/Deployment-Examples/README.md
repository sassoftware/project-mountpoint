# Project Mountpoint Deployment Exercises for 3SSC

To help prove out the portability of the 3 Starter Storage Classes (3SSC) approach, the exercises provided here take a quick-shot approach to deploying the Viya platform to each of the major Kubernetes vendors supported by SAS.

While there is a lot of variability in how each site implements their physical storage infrastructure, **all exercises rely on the exact same set of 3SSC configuration files for Viya *with no modifications***.

The purpose of Project Mountpoint is to provide a logical separation between Viya's config and the physical infrastructure. These exercises prove that point.



Enjoy!
